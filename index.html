۲. اعتبارسنجی عبارت آزمایشی BIP39

این بخش فقط صحت ساختاری ۱۲ کلمه و Checksum را بررسی می‌کند. عبارت واقعی کیف پولت را وارد نکن. برای آزمایش از عبارت ساختگی استفاده کن.

ابتدا فایل واژه‌نامه ۲۰۴۸ کلمه‌ای BIP39 را بارگذاری کن.
هنوز عبارتی بررسی نشده است.

۳. امنیت و محدودیت‌ها

از روی آدرس عمومی نمی‌توان ۱۲ کلمه بازیابی یا کلید خصوصی را استخراج کرد.

اعتبارسنجی BIP39 به معنی مالکیت کیف پول یا پیدا شدن کلید نیست. این نسخه عبارت را به آدرس بیت‌کوین تبدیل نمی‌کند.

عبارت بازیابی واقعی را در هیچ سایت یا چت وارد نکن.

یادداشت فنی

بخش آدرس برای دریافت اطلاعات عمومی به اینترنت نیاز دارد. بخش بررسی BIP39 پس از بارگذاری واژه‌نامه، محاسبات را داخل مرورگر انجام می‌دهد. هیچ داده‌ای از عبارت آزمایشی به API ارسال نمی‌شود.
